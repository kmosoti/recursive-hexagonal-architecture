# Recursive Hexagonal Architecture (RHA)

This repository holds Kennedy Mosoti's working specification of Recursive Hexagonal Architecture, v0.10, and the program that implements and tests its mechanisms: repository tooling (`xtask`), contribution records, and `rhawiki`, a pilot wiki that will render these docs. No mechanism here counts as implemented or validated until [docs/maturity.md](docs/maturity.md) says so and cites evidence.
