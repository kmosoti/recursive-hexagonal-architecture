The renderer's index is immutable configuration for one corpus. The composition root performs an additional pure analysis/assembly pass, then constructs a fresh renderer for each build. Its time and memory cost, constructor precondition and rejected alternatives are in [BDR-0006](../adr/BDR-0006-adapter-json-immutable-index.md). The active assumption ledger records the third tested implementation only after the suite passed.

These are small descriptive observations of both halves of H3, with the prerequisite assurance repair explicitly separated. They are not a controlled study or a general proof of adapter substitutability. Registered corpora are unchanged; held-out runs remain Kennedy-owned and not_run. Assumption-ledger schema coverage remains outside the registered rha-lint families; its attempted invocation and direct TOML/path checks are disclosed in the change record.

The BDR's original O(n+e) estimate is explicitly qualified in its dated implementation note: current assembly uses a linear lookup per link. This observation claims an additional pipeline pass, not a proved linear-time cost.
